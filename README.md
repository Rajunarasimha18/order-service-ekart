Order Service
Order Management Service for the E-Kart Microservices Architecture built using Spring Boot.

🚀 Tech Stack


Java 21


Spring Boot 3.5.7


Spring Data JPA


MySQL


Maven



📌 Overview
This service handles order-related operations such as order creation, order tracking, payment status, and order management within the microservices architecture.

⚙️ Features


Order Management


Order Tracking


Payment Status Handling


REST APIs


Database Integration



▶️ Run the Application
mvn spring-boot:run

🌐 API Base URL
http://localhost:8083
